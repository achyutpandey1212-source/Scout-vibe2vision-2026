# UI_UX_DESIGN_PRINCIPLES.md

# Scout Design System
### Designing Quiet Intelligence

> "Scout should never feel like a job portal.
>
> It should feel like a calm intelligence companion."

---

# Design Philosophy

Scout is an AI-powered opportunity intelligence platform.

It is NOT

❌ LinkedIn

❌ Internshala

❌ Naukri

❌ Another dashboard

Scout should feel like

- Apple
- Linear
- Raycast
- Notion
- Vercel
- Stripe Dashboard

Characteristics

- Calm
- Premium
- Intelligent
- Editorial
- Trustworthy
- Human
- Elegant

Every design decision should reinforce these values.

---

# Core Design Principle

Quiet Intelligence.

Scout should quietly work in the background.

The interface should communicate

"I've already done the hard work for you."

The user should never feel overwhelmed.

---

# Product Personality

Scout should feel like

A knowledgeable senior

not

A search engine.

It recommends.

It explains.

It guides.

It never overwhelms.

---

# Visual Language

Scout uses

Whitespace

Typography

Hierarchy

Subtle animations

instead of

Bright colors

Heavy borders

Decorative effects

The information is the hero.

Not the decoration.

---

Every component must support both themes.

No feature should launch with only one theme.

---

# Accent Color Philosophy

Scout has one primary brand color.

Muted Violet.

Accent color should only represent intelligence.

Examples

- AI insights
- Recommendation badges
- Intelligence panels
- Smart suggestions
- Loading intelligence states

Do NOT use violet everywhere.

Restraint creates identity.

---

# Typography

Large editorial headings.

Generous spacing.

Readable line heights.

Minimal font weights.

Hierarchy example

Hero

48–64px

Section Title

28–36px

Card Title

18–22px

Body

15–16px

Caption

13px

Typography should guide attention before colors do.

---

# Layout Philosophy

Every page should breathe.

Use

Large spacing

Soft grids

Consistent rhythm

Avoid

Dense tables

Tiny widgets

Crowded dashboards

If a section feels busy,

remove elements before shrinking them.

---

# Navigation

Primary Navigation

Dashboard

Saved

Notifications

Profile

No more than four primary destinations.

The homepage is the product.

Everything else supports it.

---

# Landing Page

Purpose

Build trust.

Not marketing.

Hero

Simple statement

Clear CTA

Subtle product animation

No feature overload.

---

# Authentication

Keep it invisible.

Google Sign In

Continue

Done.

No unnecessary forms.

---

# Onboarding

Must feel conversational.

Never feel like filling a government form.

Use

Cards

Chips

Progressive questions

Helpful copy

Avoid

Large forms

Dropdown-heavy layouts

Question example

❌ Desired Role

✅ Where do you hope to be one year from now?

Language matters.

---

# Intelligence Loading State

Never display

Loading...

Instead

Show progress.

Example

✓ Understanding your profile

✓ Searching trusted sources

✓ Finding hidden opportunities

✓ Ranking recommendations

✓ Preparing your dashboard

The user should feel intelligence is happening.

---

# Dashboard Philosophy

The dashboard answers one question.

"What should I do next?"

Not

"Here are 500 opportunities."

The first screen should immediately surface

Today's Best Opportunity.

---

# Dashboard Structure

Hero

↓

Featured Recommendation

↓

Hidden Gems

↓

Closing Soon

↓

Scholarships

↓

Remote Opportunities

↓

Recent Activity

Each section should contain only a few high-quality cards.

Quality over quantity.

---

# Opportunity Card

Large.

Readable.

Minimal.

Include

Organization

Title

Deadline

Tags

One-line AI explanation

Apply CTA

Never overload cards.

---

# Opportunity Detail Page

Two-column layout.

Left

Opportunity information.

Right

Scout Intelligence.

The Intelligence Panel becomes Scout's signature.

---

# Scout Intelligence Panel

Shows

Why this opportunity was recommended

Skill Match

Eligibility

Competition Estimate

Trust Score

Deadline Reminder

Suggested next action

Every recommendation should be explainable.

---

# Search Experience

Prefer Command Palette.

Ctrl + K

Search should feel instant.

Avoid dedicated cluttered search pages.

---

# Bookmark Experience

Visual.

Card-based.

Not spreadsheet-based.

---

# Profile

Minimal.

Profile

Goals

Skills

Preferences

AI Summary

Settings

No unnecessary statistics.

---

# Empty States

Every empty state should encourage.

Never punish.

Example

"No saved opportunities yet."

↓

"Let's find your first opportunity."

---

# Motion Design

Animations should feel

Natural

Soft

Purposeful

Use

Fade

Slide

Scale

Blur

Avoid

Bounce

Elastic animations

Overly playful effects

Animation duration

150–250ms

Consistent throughout the application.

---

# Components

Rounded corners

18–24px

Soft shadows

Subtle borders

Consistent spacing

Cards should appear lightweight.

---

# Icons

Use Lucide Icons.

Consistent stroke width.

Minimal.

No filled icon packs.

---

# Illustrations

Scout does not use mascots.

Instead,

Scout's decorative identity comes from Origami.

Use origami-inspired assets strategically throughout the product.

Possible motifs

- Paper Crane
- Paper Plane
- Origami Lotus
- Folded Star
- Folded Ribbon
- Abstract folded geometric shapes

Purpose

Represent transformation through intelligence.

Guidelines

- Extremely subtle
- Low visual weight
- Soft pastel tones
- Never compete with content
- Used only as supporting elements

Origami should become part of Scout's visual identity.

---

# Accessibility

Minimum contrast compliance.

Keyboard navigation.

Visible focus states.

Semantic HTML.

Screen-reader friendly.

Accessibility is a feature.

Not an afterthought.

---

# Responsive Design

Desktop first.

Tablet optimized.

Mobile fully supported.

No hidden functionality across devices.

---

# Design Consistency Rules

Never use multiple accent colors.

Never use unnecessary gradients.

Never create pages with more than one primary CTA.

Never overload users with data.

Never use decoration without purpose.

Always prioritize readability.

Always explain recommendations.

Always maintain visual rhythm.

---

# Brand Keywords

If every screen had to be described using five words,

they should be

Calm

Intelligent

Elegant

Trustworthy

Hopeful

---

# North Star

Every interaction should make the user feel

"I don't have to search anymore.

Scout already found what matters."# UI_UX_DESIGN_PRINCIPLES.md
